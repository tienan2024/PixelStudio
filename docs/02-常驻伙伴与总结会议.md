# 常驻伙伴与总结会议

最后更新：2026-09-28

## 身份与数据边界

画面中的两个角色是固定的 Codex / Kimi 伙伴，分别绑定 `companion:codex` 和 `companion:kimi`。保留银紫短发、栗色马尾造型与待机动画，不再绑定历史子代理 ID；角色常驻不表示有两个实际子代理正在执行。成员卡展示任务或模型调用状态。原任务列表、额度与历史小记仍使用原数据来源。

`companion_sources.py` 在独立后台线程读取状态；每次完成采样后约 2 秒再采样。额度与原线程列表仍每 20 秒更新。读取失败显示未知；界面超过 15 秒没有收到新快照也会清除忙碌显示。Tk 主线程只接收队列结果。

## Codex 伙伴

- 只读 `$CODEX_HOME`（默认 `~/.codex`）下最高数字版本 `state_N.sqlite` 与 `thread_history_N.sqlite`，短连接 `mode=ro`，不写库，不使用忽略 WAL 的 immutable 模式。
- 读取主线程名称、模型、更新时间以及每个线程**最新一轮**的状态；排除子代理。最多取近期 32 个主线程，不能把历史遗留的 inProgress 当作当前一轮。
- 最新轮次 inProgress 且有 15 分钟内活动时显示执行中；多个运行任务选择最近活动的任务并注明数量。过旧的 inProgress 标为状态待确认，不能自动宣称已完成。
- completed / interrupted / failed 分别显示最近完成、中止和失败。未加载或源不可用显示未知。SQLite 不兼容时回退 app-server 线程列表，只有明确的 active 才算运行；列表读取失败或距上次成功读取超过 60 秒时停止使用旧列表。
- 任务标题来自线程名称；它代表最近活动的任务，不代表用户当前前台选中的聊天。读取的是本地内部投影，Codex 升级改变表结构时可能降级。
- 仅取最终答复的 `phase` 元数据，不读取用户消息、工具正文、认证文件或模型输出文本。运行中的 final_answer 阶段用于触发总结会。

## Kimi 伙伴

默认读取 `http://127.0.0.1:15723/activity`；可用 `PIXELSTUDIO_GATEWAY_URL` 修改回环网关根地址。只允许 HTTP 回环主机，不发认证头，不使用环境代理，拒绝远程重定向，单次请求超时 1.5 秒、响应上限 128 KiB。

接口要求 `service=codex-model-gateway`、`schema_version=1`、`observed_at` Unix 秒以及 `active` / `recent` 数组；只接受 `route=kimi` 且模型为 kimi-for-coding / k3 / k3-256k 的记录。调用中显示模型、阶段、耗时与并发数；无调用显示空闲与最近传输结果。近期 60 秒内失败显示异常，快照超过 15 秒显示过期。404 显示未接入，连接失败显示网关离线。

网关扩展位于本机多模型路由项目的 `router/kimi_bridge.py` 和 `router/activity_status.py`；它是可选的数据源，不是 PixelStudio 内置服务。旧网关需要在空闲时重载才能提供 `/activity`。Kimi Code 配额读取和模型调用状态互相独立。HTTP 传输结束不能当作整个任务完成；网关没有活动也可能是代理在执行本机工具。

## 总结会议

会议室是独立的第四个房间配置，排列在工作室之后；总地图宽 2240px，视口仍最多 1120×224px。会议桌、两把椅子、白板均为独立物品。桌子为 40 层前景，角色在桌子后入座；点击按前景、角色、后景顺序做透明像素命中。

- Codex 进入最终答复阶段，或组件观察到同一轮从执行中变成刚完成，自动召集两位伙伴。结束信号后保留约 35 秒，再回到正常活动区域；新任务开始可提前结束自动会议。
- 自动会议不会在组件启动时重放旧的完成记录，也不会由每次 Kimi 传输结束触发。缺少阶段信号时不猜测“正在总结”。
- 点击“开总结会”、会议白板或长桌可手动集合，再次点击结束；手动会议持续到用户结束。结束自动会议后，同一轮不反复召集。
- 自动到期、手动结束或新任务提前结束会议时，伙伴恢复正常活动位置；若镜头仍在会议室，则回到工作室，已切换到其他房间的镜头保持原位。
- 总结会只控制角色的场景位置，不改变真实任务、模型或运行状态；下方卡片始终保留原始状态。
- 顶部四个房间按钮、`1–4` 或方向键切换，滚轮横向浏览。自动集合时，已展开的画卷会定位会议室；画卷折叠时不主动撑开窗口。

会议不写入家具存档，重启后恢复正常活动；家具开关等持久化行为保持原样。
