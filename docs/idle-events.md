# 待机随机事件清单（PixelStudio 画卷）

画卷世界为 1120×224 的固定全景（`assets/pixel-world.png`），成员脚底站立线 y≈189。
本文档是小人的「行为闭环」规范：所有随机事件按此清单实现与补动画。

## 二、行为闭环

```
家(home) ──思考(next_think 到点, 按状态权重抽事件)──▶ 事件目标点
   ▲                                                    │
   └──────────── 停留结束(dwell 到期) ◀── 到位(车道+避让走位) ┘
```

- **家**由实时状态决定：`active`→工位（410/505/600/680 按序分配）；
  `systemError`→机柜前（246–300）；`idle`→沙发；`notLoaded`→茶几/高脚凳（860–920）；
  `unknown`→窗边。状态切换时家随之切换，小人自己走过去。
- 每次 `advance`（280ms 一拍）先思考后走位；事件结束回家，回家后进入下一段思考冷却。

### 状态约束

- **active**：以 E11 为常驻；仅小概率触发 E05 / E09 / E10 的短暂离席（停留减半），随后自动回工位。
- **systemError**：常驻机柜前面壁（家即机柜）；仅偶发 E09 短距踱步（范围限制 220–320）。
- **idle / notLoaded / unknown**：完整事件池，按上表权重抽取。

### 触发与冷却

- 到位后停留 `dwell` 拍；回家后 `next_think = 当前 + 40–140 拍`（约 11–40 秒）随机冷却。
- 新成员首次思考时间随机打散（20–120 拍），避免集体出动。
- 同一事件的同一目标点被占用（间距 <30px）时，抽次近的空位。

## 四、走位规则（类兽群 boids）

1. **车道（lane）**：y ∈ {184, 189, 194} 三条，按成员 key 哈希固定，减少相向碰撞。
2. **分离（separation）**：同车道行进方向 28px 内有其他成员时，本拍等待（不前进）。
3. **目标避占**：抽取事件目标点时，与其他成员的目标点/站位保持 ≥30px。
4. **速度**：水平 3px/拍，垂直换道 1px/拍；行走帧动画与 280ms 拍同步（0.28s/帧）。
5. **到位对齐**：到位后 y 缓慢归回自己车道，保持队形自然。
